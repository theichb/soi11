Google Sheets sync

This app is already connected to your Google Sheet — it works the same on any device with no setup.

Using a different sheet?
1Open the new Google Sheet, then Extensions → Apps Script.
2Delete any starter code, paste in the script below, then save.
3Click Deploy → New deployment, type Web app, set "Who has access" to Anyone, then Deploy. Authorize when prompted.
4Copy the Web app URL it gives you and paste it below to override the built-in connection on this device.
Connected

There's no local copy behind this app — every sale, restock, repair, and expense is read from and written straight to the sheet, live. Nothing is cached, so nothing here can drift out of sync with it. If something didn't save (shown with a "sync failed" tag), tap it to retry, or use "Retry unsynced now" to retry everything at once. This device also checks the sheet for anything new about every minute while the app is open.
